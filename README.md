# 読書タイプ診断

はい・いいえの5問に答えると、20冊の中から1冊を推薦するアプリです。Nuxt、Bulmaで作り、Netlifyで公開します。

> [!NOTE]
> [`reading-list-20.md`](reading-list-20.md) の特徴とあらすじには、作品の仕掛けの種類に触れる記述があります。[`tests/scoring.test.ts`](tests/scoring.test.ts) の禁止語リストにも、内容を連想させる語があります。先入観なく作品を読みたい方はご注意ください。アプリの質問と結果の画面には、結末やトリックの分類を表示しません。

## 開発

```sh
pnpm install
pnpm dev        # 開発サーバー
pnpm test       # テスト
pnpm generate   # 静的サイトを dist に生成
```

## 採点の仕組み

各書籍は質問ごとの配点（app/data/books.ts の scores）を持ちます。「はい」なら配点を加算し、「いいえ」なら減算して、点の高い順に候補を並べます。同点のときは一覧で先にある本を先にします。ただし、回答と強く矛盾する本（「はい」と答えた設問の配点が -2 以下、または「いいえ」と答えた設問の配点が 2 以上の本）は候補から除きます。最初に候補の1番目を推薦します。結果画面で「この本は読んだことがある」を押すと次の候補を表示し、「1つ前の本に戻る」で前の本に戻れます。候補がなくなると「ほかにおすすめできる本がありません」と表示します。読了の情報は保存しないので、「もう一度診断する」を押すと最初の候補に戻ります。
