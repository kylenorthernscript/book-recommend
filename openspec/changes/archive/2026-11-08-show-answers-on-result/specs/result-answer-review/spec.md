# Spec Delta

## Purpose

診断の結果画面で、利用者が自分の答えた設問と回答を推薦結果と一緒に振り返れるようにする。

## ADDED Requirements

### Requirement: 結果画面に設問と回答を表示する
システムは、結果画面に、すべての設問文とそれぞれの回答を出題順に表示しなければならない（SHALL）。回答は「はい」または「いいえ」の文字で示さなければならない（MUST）。

#### Scenario: 5問に答えて結果画面を開く
- **WHEN** 利用者が5問すべてに回答して結果画面が表示される
- **THEN** 5問の設問文が出題順に表示され、各設問にその利用者の回答が「はい」または「いいえ」で添えられている

#### Scenario: はいといいえが混在する
- **WHEN** 利用者が1問目に「はい」、2問目に「いいえ」と回答して診断を終える
- **THEN** 結果画面で1問目には「はい」、2問目には「いいえ」が表示される

### Requirement: 振り返りは推薦結果の後に表示する
システムは、回答の振り返りを、推薦された本の情報の後、「もう一度診断する」ボタンの前に表示しなければならない（SHALL）。結果画面に切り替わったときのフォーカスは、これまでどおり本の書名の見出しに移さなければならない（MUST）。

#### Scenario: 結果画面の並び順
- **WHEN** 結果画面が表示される
- **THEN** 本の書名、著者、紹介文、回答の振り返り、「もう一度診断する」ボタンの順に表示される

#### Scenario: 結果画面へのフォーカス移動
- **WHEN** 最後の設問に回答して結果画面に切り替わる
- **THEN** フォーカスは本の書名の見出しに移る

### Requirement: 振り返りは最終的な回答を反映する
システムは、回答を変更した場合、変更後の回答だけを振り返りに表示しなければならない（SHALL）。

#### Scenario: 前の設問に戻って回答を変える
- **WHEN** 利用者が「ひとつ前に戻る」で設問に戻り、回答を「はい」から「いいえ」に変えて診断を終える
- **THEN** 結果画面のその設問には「いいえ」だけが表示される

#### Scenario: もう一度診断する
- **WHEN** 利用者が「もう一度診断する」を押して、新しい回答で診断を終える
- **THEN** 結果画面には新しい回答だけが表示される

### Requirement: 振り返りにネタバレを含めない
システムは、振り返りに、設問文と「はい」「いいえ」以外の作品や回答に関する説明を表示してはならない（MUST NOT）。

#### Scenario: 振り返りの表示内容
- **WHEN** 結果画面の振り返りが表示される
- **THEN** 振り返りの見出しを除き、表示される文章は設問文と「はい」「いいえ」だけである
