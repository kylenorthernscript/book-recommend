# Spec Delta

## MODIFIED Requirements

### Requirement: 振り返りは推薦結果の後に表示する
システムは、回答の振り返りを、推薦された本の情報の後、「もう一度診断する」ボタンの前に表示しなければならない（SHALL）。推薦できる本が残っていない場合は、本の情報の代わりの見出しの後に振り返りを表示しなければならない（MUST）。結果画面に切り替わったときのフォーカスは、これまでどおり本の書名の見出しに移さなければならない（MUST）。

#### Scenario: 結果画面の並び順
- **WHEN** 最初の推薦の結果画面が表示される
- **THEN** 本の書名、著者、紹介文、回答の振り返り、「この本は読んだことがある」ボタン、「もう一度診断する」ボタンの順に表示される

#### Scenario: 2冊目以降の推薦の並び順
- **WHEN** 「この本は読んだことがある」を押して別の本が推薦されている結果画面が表示される
- **THEN** 本の書名、著者、紹介文、回答の振り返り、「この本は読んだことがある」ボタン、「1つ前の本に戻る」ボタン、「もう一度診断する」ボタンの順に表示される

#### Scenario: 推薦できる本が残っていない場合の並び順
- **WHEN** 推薦できる本が残っていない結果画面が表示される
- **THEN** 本がないことを伝える見出し、回答の振り返り、「1つ前の本に戻る」ボタン、「もう一度診断する」ボタンの順に表示される

#### Scenario: 結果画面へのフォーカス移動
- **WHEN** 最後の設問に回答して結果画面に切り替わる
- **THEN** フォーカスは本の書名の見出しに移る
